## Context

This screener targets **known Samsung DSR employees** who are existing PM Planner users or future IRIS stakeholders. IRIS is a **new build** resource planning platform replacing the legacy PM Planner system. The screener serves four purposes:

1. **Profile** each stakeholder's role, PM Planner usage patterns, and pain severity
2. **Assign** participants to the correct interview track (Planner / Manager / Analyst / HR / IT)
3. **Prioritize** participants by relevance, pain level, and availability
4. **Baseline** quantitative data before qualitative interviews begin

Distribution is coordinated through the Samsung DSR project sponsor, not public channels.

### Priority Tiers

| Tier                 | Score Range | Action                                                                               | Profile                                                        |
| -------------------- | ----------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------- |
| **Priority 1**       | 16-20       | Schedule immediately — these are core users with high pain and deep system knowledge | Daily PM Planner users, high frustration, eager to participate |
| **Priority 2**       | 12-15       | Schedule if slots available — strong fit with good perspective                       | Regular users with moderate pain, available for interview      |
| **Priority 3**       | 8-11        | Waitlist — useful perspective but lower priority                                     | Occasional users or report consumers, lower pain threshold     |
| **Does Not Qualify** | Below 8     | Thank and exclude — does not meet minimum criteria                                   | Insufficient system interaction or unavailable                 |

### Minimum Hard Requirements

All three conditions must be met regardless of total score. Failure on any one is an automatic disqualification:

1. **Q3 — Tenure**: Must have 6+ months in current Samsung role (respondents selecting "Less than 6 months" are excluded)
2. **Q4 — PM Planner Interaction**: Must have at least indirect interaction with PM Planner or resource planning outputs (respondents selecting only the last option with no system awareness are excluded)
3. **Q14 — Willingness**: Must answer "Yes" or "Maybe" (respondents answering "No" are excluded)

### CXO Readiness Rating

| Rating     | Criteria                                     | Interview Implication                                                               |
| ---------- | -------------------------------------------- | ----------------------------------------------------------------------------------- |
| **High**   | High on 2+ of the 3 CXO indicators           | Ideal for contextual inquiry, journey mapping, empathy mapping, and concept testing |
| **Medium** | Mix of High and Medium/Low across indicators | Good for structured interviews; may need guided prompting for emotional detail      |
| **Low**    | Low on 2+ of the 3 CXO indicators            | Best for focused task-based questions; supplement with observation-based research   |

> **CXO Note**: Participants rated "Low" are not excluded. They provide valuable task-level data. However, plan interview approach accordingly — use more structured questions and avoid open-ended emotional prompts. Pair Low-rated participants with an observer to capture behavioral signals they may not verbalize.

## Interview Track Assignment

Based on screener responses, assign each qualified participant to one primary interview track. A participant may be flagged for a secondary track if their responses span multiple areas.

| Track             | Primary Focus Areas                                                                                                          | Assignment Criteria                                                                                       | Target Participants |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ------------------- |
| **Planner Track** | P/M workflow, concurrent editing pain, version management, simulation needs, daily planning tasks                            | Q4 = creates/edits plans directly; Q1 = Resource Planner; Q6 top features include P/M Planning or Roadmap | 3-4 participants    |
| **Manager Track** | Approval workflow, cross-department oversight, version review, strategic decision-making, cross-site visibility              | Q1 = Planning Manager or Division Manager; Q4 = reviews/approves plans                                    | 2-3 participants    |
| **Analyst Track** | Reporting, analysis views, world map dashboard, AI-based reporting, factor control, data exports                             | Q1 = Analyst; Q6 top features include Analysis/Reporting or Factor Control                                | 2-3 participants    |
| **HR Track**      | HeadCount Portfolio, staffing plans, gap analysis, HR data integration (GHRP), workforce planning                            | Q1 = HR Planner; Q6 top feature includes HeadCount Portfolio                                              | 1-2 participants    |
| **IT Track**      | Infrastructure, integrations (N-PLM, PROMIS, Samsung AI Services), Elasticsearch cluster, Mendix platform, server deployment | Q1 = Site Admin or IT System Admin; Q4 = manages infrastructure or integrations                           | 1-2 participants    |

### Track Assignment Decision Tree

```
IF Q1 contains "Planner" AND Q4 includes "create/edit plans"
    → Assign PLANNER TRACK

ELSE IF Q1 contains "Manager" OR Q4 includes "review/approve"
    → Assign MANAGER TRACK

ELSE IF Q1 contains "Analyst" OR Q6 top features = Analysis/Reporting
    → Assign ANALYST TRACK

ELSE IF Q1 contains "HR" OR Q6 top feature = HeadCount Portfolio
    → Assign HR TRACK

ELSE IF Q1 contains "Admin" OR "IT" OR Q4 includes "infrastructure/integrations"
    → Assign IT TRACK

ELSE
    → Flag for manual review by CXO
```
