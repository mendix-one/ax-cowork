# app-layout

Mendix pluggable widget scaffold that provides a 5-region layout shell with widget slots:

- `header`
- `left`
- `content`
- `right`
- `footer`

## Scripts

- `pnpm --filter @ax-cowork/mx-app-layout run dev`
- `pnpm --filter @ax-cowork/mx-app-layout run build`
- `pnpm --filter @ax-cowork/mx-app-layout run type-check`
- `pnpm --filter @ax-cowork/mx-app-layout run lint`
